Pentru rularea si construirea acestui build este necesar Cmake si ninja .
Ca sa compilezi intreg programul incluzand Compilerul trebuie sa deschizi un terminal si sa navighezi pana catre directorul main 
al vm-ului VM , pe urma trebuie sa introduci comanda cmake -B build -G Ninja , pe urama Ninja -C build , iar programul ar trebui sa fie gata compilat 
Important : 
  Calea catre fisierul sursa sunt cai fixe ce trebuie schimbate in fisierul VM_Config.h care se afla in subdirectorul Resurse . Aceste cai se afla exact la finalul fisierului
